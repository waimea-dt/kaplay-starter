# Kaplay Starter

A starting point for making games with **JavaScript** and [Kaplay](https://kaplayjs.com).

The game can be [viewed and played here](https://waimea-dt.github.io/kaplay-starter/)

## How to run it locally

Your browser needs a tiny **web server** to load pictures and sounds - double-clicking `index.html` won't work.

In **VS Code**:
- Install the **Live Server** extension
- Right-click `index.html`
- Choose **Open with Live Server**

## Debugging

If the screen is blank, open the browser **Dev Tools** by pressing **F12** / **Ctrl**+**Shift**+**i** and look at the **Console** tab. Any errors will be displayed there

## Files in this Project

| Name               | What it is                                 |
| ------------------ | ------------------------------------------ |
| `index.html`       | The web page that loads Kaplay and thegame |
| `main.js`          | Game code                                  |
| `assets/images/`   | Pictures for the game                      |
| `assets/sounds/`   | Sounds for the game (empty for now)        |
| `assets/scenes/`   | Game scenes (empty for now)                |
| `assets/entities/` | Game entities (empty for now)              |
| `assets/data/`     | Game data (empty for now)                  |
| `lib/kaplay.js`    | The Kaplay library (version 4000)          |
| `favicon.ico`      | The little icon in the browser tab         |
